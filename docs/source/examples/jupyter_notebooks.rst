Jupyter Notebooks
=================

Interactive notebooks showing end-to-end usage of LibHankel, including plots.
You can browse the rendered output below, download the notebooks from the
`repository <https://github.com/libhankel/libhankel/tree/main/docs/source/examples/notebooks>`_
and run them locally, or launch them interactively in your browser via Binder
(no installation required — see the note at the top of each notebook page).
